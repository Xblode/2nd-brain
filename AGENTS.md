# Instructions des agents

Lire `brain/STATE.md` avant un travail substantiel. `brain-main/` est le système commun. `brain/` est la mémoire de ce dépôt. `brain-main/templates/project/` est le modèle des autres projets.

- Commencer par le brainstorming et le cadrage. Ne pas lancer un agent de code tant que le lot n'est pas choisi.
- Regrouper les modifications liées avant de les exécuter.
- Proposer toute écriture durable et attendre une validation humaine. Le modèle ne s'approuve pas lui-même.
- Ne jamais écrire dans `brain/inbox/` ni dans l'Inbox d'un projet.
- Les fichiers canoniques priment. SQLite n'est qu'un index reconstructible.
- Ne pas créer un fichier par idée ou par conversation.
- `.clickup/` et `.notion/` documentent des correspondances de projet. Ils ne connectent pas un serveur MCP.
- Avant une action externe (GitHub, ClickUp, Notion), décrire l'action exacte et obtenir une approbation, sauf si cette action précise a déjà été autorisée.
- Ne jamais committer de jeton, secret ou mot de passe.
- Ne pas présenter un composant de ce squelette comme implémenté.
