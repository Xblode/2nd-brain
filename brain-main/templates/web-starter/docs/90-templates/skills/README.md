# Catalogue de skills optionnels (profil)

Ces skills sont **disponibles** dans le pack. Ils ne sont pas installés tant qu’ils ne sont pas copiés sous `.cursor/skills/` (via `/build` après accord).

## Installation

`docs/90-templates/skills/<nom>/` → `.cursor/skills/<nom>/`  
Puis mettre à jour `docs/00-discovery/SKILLS_SELECTION.md`. Nouvelle conversation Cursor pour vérifier.
