# Principes

1. Fichiers canoniques = source de vérité ; SQLite = index dérivé seulement.
2. Écriture durable = proposition puis approbation humaine.
3. Inbox manuelle uniquement — aucune IA n’écrit dans `brain/inbox/`.
4. Anti-perte : toute idée a une destination ; pas de suppression silencieuse.
5. Local SoT ; ClickUp = projection.
6. Aucun secret dans Git.
7. Brainstorming = entrées `proposed` ; promotion via `/build` ou accord explicite.
