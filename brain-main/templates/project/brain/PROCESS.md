# Processus

```text
Prompt → brainstorm → registre (proposed) → /build → validation
      → local → /clickup
```

1. **Brainstorm** — `/note` / agents : entrées `proposed` ; pas de promotion auto en tâches.
2. **`/build`** — analyser, trier, valider les choix structurants, écrire en local.
3. **ClickUp** — projection du lot local validé.
4. **Exécution** — `/faire` sur un lot déjà approuvé.
5. **Consolidation** — maj `STATE` et docs cadrage ; preuves avant `/done`.

Détail système : `{brain_main_path}/skills/COMMANDS.md`.
