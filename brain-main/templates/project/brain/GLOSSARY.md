# Glossaire

| Terme | Sens |
| --- | --- |
| `proposed` | Entrée brainstorm non encore validée |
| `accepted` / `settled` / `active` / `resolved` | Statuts selon kind — voir taxonomy |
| Registre | Collections JSONL (`DECISIONS`, `TASKS`, `registry/`) |
| Doc cadrage | `.md` obligatoire (objectifs, process…) |
| Lot | Ensemble de changements avec critères |
| `/build` | Organisation globale du registre → local → ClickUp |
| Projection | Vue ClickUp ; local = SoT |

Promotion : nouvelle entrée liée (`derived_from`), pas de changement de kind in-place.
