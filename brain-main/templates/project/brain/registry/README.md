# Registre

- **Role:** collections atomiques pour kinds sans foyer de synthèse (`fact`, `hypothesis`, `idea`, `issue`, `reference`).
- **Scope:** un fichier collection par kind, jamais un fichier Markdown par idée.
- **Boundaries:** décisions/questions → `../DECISIONS.md` ; tâches → `../TASKS.md`.
- **Format:** Markdown + bloc `jsonl` (DEC-009).
- **Status:** créer une collection seulement au besoin ; `proposed` OK en volume ; promotion via `/build`.
