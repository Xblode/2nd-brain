# Scripts

Emplacement prévu pour l'installation du modèle de projet, la validation et la maintenance.

Aucun script de génération n'est fourni. Le déploiement du template (ce qui est copié, ce qui reste lié à `brain-main/`, comment une mise à jour préserve les personnalisations) est une décision ouverte. Ne pas écraser un projet avec un script tant que cette décision n'est pas prise.
