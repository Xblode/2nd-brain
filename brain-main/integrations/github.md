# GitHub

GitHub porte le code, l'historique, les issues et les pull requests. Les décisions durables restent dans la mémoire du projet.

Fichiers natifs : `.github/copilot-instructions.md`, `.github/ISSUE_TEMPLATE/`, `.github/PULL_REQUEST_TEMPLATE.md`, plus `AGENTS.md` et `CLAUDE.md` à la racine du dépôt concerné.

Avant de créer, commenter, fermer ou publier : montrer l'action et obtenir une approbation, sauf autorisation déjà donnée pour cette action. Une issue n'est pas automatiquement une décision canonique.
