# 02 — Workflow utilisateur

Aligné sur `brain/PROCESS.md` (loi projet) et DEC-011.

1. **Prompt / brainstorm.** L’humain discute ; agents et `/note` accumulent des entrées registre en `proposed`.
2. **Stockage registre.** Idées, hypothèses, questions, faits candidats — sans promotion automatique en tâches.
3. **`/build` (organisation).** Analyse, tri, fusion, promotion proposée vers tâches / décisions / patches docs cadrage. Validation humaine sélective.
4. **Local validé.** Application des écritures approuvées dans `brain/`.
5. **ClickUp.** `/clickup` projette le lot local validé (prévisualisation → accord → push). ClickUp ≠ SoT.
6. **Exécution.** `/faire` sur un lot de code déjà approuvé.
7. **Consolidation.** Maj `STATE.md` et docs cadrage ; preuves avant `/done`.

Les docs de cadrage obligatoires (`OBJECTIVES`, `ROADMAP`, `PRINCIPLES`, `PROCESS`, `ARCHITECTURE`, `GLOSSARY`, `STATE`, `README`) guident le filtrage et le tri. Inbox = capture manuelle seulement.
