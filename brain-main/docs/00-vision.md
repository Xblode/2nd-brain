# 00 — Vision

Les agents perdent le contexte entre les sessions, mélangent idées et décisions, et peuvent coder avant que le besoin soit cadré.

Second Brain est une mémoire locale, portable et inspectable. Le chat sert d'abord à réfléchir : questions, angles morts, contradictions, puis lots de travail. Le passage à un agent de code est un choix explicite.

## Résultat attendu

- Reprendre un projet sans reconstituer tout l'historique.
- Distinguer fait, hypothèse, idée, question et décision.
- Garder la mémoire dans des fichiers lisibles.
- Retrouver une information sans relire tout le corpus.

## Hors périmètre actuel

- Écriture durable sans validation humaine.
- Base opaque à la place des fichiers.
- Un document par conversation.
- Implémentation du cœur, du MCP ou de la CLI.

## Critère de réussite du squelette

Un nouvel agent identifie l'état, les contraintes, et ce qui n'est pas encore décidé.
