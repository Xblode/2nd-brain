# Serveur MCP

Emplacement de l'interface MCP locale. Elle devra exposer le cœur métier sans lui ajouter de permissions.

Outils envisagés, non implémentés : état, recherche, lecture, proposition, validation, reconstruction d'index. L'Inbox n'est pas une cible d'écriture. Le système doit rester utilisable avec les fichiers seuls.
