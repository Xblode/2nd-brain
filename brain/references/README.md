# Références

- **Role:** références externes durables (titre, URL, date de consultation, résumé court).
- **Scope:** pointeurs vérifiables, pas de copie intégrale de contenu protégé.
- **Boundaries:** pas de secrets ; les entrées atomiques `reference` du registre, si besoin, vivent sous `registry/` au format JSONL.
- **Status:** emplacement documentaire ; pas de moteur.
